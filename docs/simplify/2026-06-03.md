# Simplify 审查摘要 — 2026-06-03

## 范围

全项目审查，35 个源文件（Python 后端 + TypeScript 前端 + 文档）。

## 修复清单（11 项）

### 效率

- **steel_load_generator.py**：恒载与活载两次独立遍历合并为一次，构件循环减半，从属宽度只算一次。

### 简化

- **steel_frame_pipeline.py**：`_call` 方法回退逻辑中消除五条目冗余映射字典（所有条目的工具名与键一致）。
- **ResultsPanel.tsx + InputPanel.tsx**：约 170 行 mock 数据生成逻辑提取到 `utils/mockData.ts`，组件文件大幅缩减。

### 复用

- **新建 `servers/defaults.py`**：集中管理截面库、材料库、默认设计参数、荷载组合系数、颜色梯度定义。消除 Python 端三处重复。
- **steel_frame_generator.py**：截面库和材料库改为从 `defaults` 导入。
- **steel_code_check.py**：荷载组合系数改为从 `defaults` 导入，消除 `check_code` 和 `_generate_calc_processes` 两处内联重复。
- **llm_param_extractor.py**：默认参数字典改为从 `defaults` 导入。
- **cli_orchestrator.py**：quick 模式和默认模式参数改为从 `defaults` 获取。
- **前端 InputPanel.tsx**：柱截面、梁截面、钢材三个下拉列表从硬编码改为启动时从 `/api/sections` 动态获取。
- **颜色映射统一**：`defaults.py` 定义唯一色标梯度，`three_d_exporter.py` 改为色标间插值，`ResultsPanel.tsx` 的五个离散阈值与后端严格对齐（修复了原有两个阈值重叠导致黄色层死代码的缺陷）。

### 高度

- **CLAUDE.md**：移除过时的 Windows 端口强杀命令，改为说明 `strictPort` 行为。
- **docs/quickstart.md**：同上，并修正"端口被占用时自动递增"的错误描述。
- **web_api_server.py**：端口检测从 Windows 专有命令（`netstat`/`findstr`/`taskkill`）改为跨平台 `socket` 检测，与前端 `strictPort` 策略一致。

## 新增文件

- `servers/defaults.py` — 共享配置模块
- `frontend/src/utils/mockData.ts` — 前端模拟数据工具

## 新增 API 端点

- `GET /api/sections` — 截面库和材料库
- `GET /api/colormap` — 应力比颜色映射定义

## 测试结果

- 后端：19/19 全部通过（修复了 2 个因缺少子进程注册导致的已有测试失败）
- 前端：TypeScript 编译零错误

## 未修改项（跨语言限制）

- 应力比颜色映射算法已统一为 `defaults.py` 色标定义，前端通过 `/api/colormap` 获取。但前端的 `stressColor` 函数仍为本地方案，可在后续从 API 动态加载阈值。
